## Draft Report Notes

This project builds an AI agent for real-product e-commerce search. The agent
extends a language model with information retrieval actions: live web search,
taxonomy-aware query refinement, candidate memory, reranking, and loop stopping
through state equivalence.

The system is intended to show how agentic behavior can improve context
gathering. Instead of answering directly from parametric memory, the agent
actively searches for current product pages, extracts structured candidates,
refines weak searches, and returns a top-10 ranked product list.
