# Taxonomy Search

When this skill is active:

1. Infer the likely product category from the user query.
2. Infer useful category-specific attributes such as material, activity,
   compatibility, size, color, target user, and price constraints.
3. Use Shopify and Google product taxonomy concepts as vocabulary hints.
4. Preserve hard constraints exactly.
5. Do not over-specialize the query by adding a brand unless the user named it.
6. Use category and attribute terms to improve retrieval context.
